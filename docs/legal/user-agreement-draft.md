## 二、服务内容

灵序穿搭主要提供：

1. 基于公历、农历、传统五行颜色规则生成的每日颜色建议。
2. 结合用户所选城市或授权定位城市的天气数据，提供穿衣搭配和一般出行护理建议。
3. 通勤、休闲、度假等场景的穿搭素材展示、收藏和浏览记录。
4. 签到积分、广告解锁、积分解锁等互动功能。
5. 我们后续依法提供并在页面中说明的其他功能。

每日颜色、穿搭和配饰内容属于传统文化创意及生活方式参考，不构成对运势、健康、医疗、投资、消费结果或其他实际效果的承诺。天气和生活指数可能因数据来源、更新时间、定位精度及现实环境变化而存在偏差，您应结合实际情况自行判断。

## 三、账号登录与使用

1. 您可通过微信授权方式登录。登录时，我们可能在取得授权后获取微信昵称、头像及用于识别账号的标识。
2. 您应妥善保管微信账号及设备。因您主动泄露、出借账号或设备管理不当造成的损失，由您依法承担相应责任。
3. 如发现账号被异常使用，请通过本协议列明的联系方式及时联系我们。
4. 您不得冒用他人身份、恶意注册、批量操作、利用程序自动刷取积分或广告奖励。

## 四、积分、签到与内容解锁

1. 积分是本服务中的虚拟计数单位，仅用于参与小程序内明确展示的活动和内容解锁。
2. 积分不属于货币、储值或金融产品，不可提现、转让、交易或兑换现金。
3. 连续签到奖励、补签、广告奖励、积分消耗及解锁范围，以小程序当时展示且已生效的规则为准。
4. 观看激励视频需完整满足页面提示的完成条件。因主动关闭、网络异常或广告平台未返回有效完成结果，可能无法获得奖励。
5. 对于程序错误、恶意刷取、作弊或违反活动规则获得的积分和权益，我们有权在核实后撤销异常记录，并保留追究责任的权利。
6. 规则发生实质变化时，我们将通过页面公告、弹窗或其他合理方式提示。

1. 发布、传播或存储违反法律法规、社会公德或侵害他人合法权益的内容。
2. 干扰服务器、数据库、广告验证、积分计算或正常运营。
3. 反向破解、未经授权抓取、复制、出售或批量利用本服务数据和素材。
4. 侵犯他人的著作权、商标权、肖像权、隐私权或其他合法权益。
5. 从事其他违法违规或损害本服务安全与正常秩序的行为。

## 九、责任范围

我们将依法保障服务安全和用户权益，但不对下列情形作超出法律规定的保证：

1. 天气、穿搭、颜色、配饰及出行护理建议完全符合每个用户的身体状况、审美或现实环境。
2. 第三方数据在所有时间均准确、连续或无延迟。
3. 因用户自行判断、未结合实际天气或不当使用建议造成的损失。
4. 因不可抗力、基础通信故障或非我们可合理控制的第三方原因造成的中断。

本条不排除法律规定不得限制或免除的责任。
