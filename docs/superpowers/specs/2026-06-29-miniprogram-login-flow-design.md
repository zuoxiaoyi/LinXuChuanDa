# 小程序登录与穿搭详情闭环设计

## 目标

复用现有 `pages/login/login` 页面，按原型编号 3 重做登录界面，并完成“首页穿搭详情 → 登录 → 原日期详情页”的闭环。

本次不接入天气 API、万年历算法，也不调整详情页主体视觉。

## 页面与视觉

- 登录页背景复用 `/images/splash/bg.png`，不新增大尺寸图片资源。
- 顶部使用现有自定义导航栏，标题为“灵序穿搭”。
- 保留开屏背景中的古风人物、品牌标题和发光文案。
- 页面底部设置金色“微信授权一键登录”按钮。
- 登录按钮支持加载态和防重复点击。
- 按钮下方保留低调的“暂不登录，返回首页”入口。
- 错误提示显示在按钮区域附近，不使用阻塞式弹窗。

## 跳转流程

### 未登录查看详情

1. 用户在首页选择日期并点击“穿搭详情”。
2. 首页判断当前未登录，不再显示“需要登录”确认弹窗。
3. 首页通过 `wx.navigateTo` 打开 `pages/login/login`，使用 URL 编码后的 `redirect` 参数携带：
   - `/pages/detail/detail`
   - 当前 `dateIndex`
4. 用户登录成功后，登录页通过 `wx.redirectTo` 打开目标详情页。
5. 详情页再次校验登录态，避免通过分享链接或手工路径绕过。

### 暂不登录

- 点击“暂不登录，返回首页”时，不进入详情页。
- 若登录页是从首页打开，则返回上一页。
- 若页面栈中没有可返回页面，则通过 `wx.reLaunch` 打开首页。

### 已登录访问

- 已登录用户点击“穿搭详情”时直接打开详情页。
- 已登录用户意外进入登录页时：
  - 存在合法 `redirect` 时直接跳转目标页。
  - 不存在合法 `redirect` 时返回上一页或首页。

## 登录与会话

- 微信授权操作必须由用户点击按钮触发。
- 登录页调用现有 `login` 云函数创建或更新 `users` 记录。
- 登录成功后保存前端展示所需的用户资料，并更新全局登录状态、OpenID 和积分。
- 登录判断不能只依赖本地 `userInfo`：
  - 本地信息用于快速恢复页面状态。
  - 进入受保护页面或执行收藏、签到等操作时，以云函数调用身份和云端用户记录为准。
- 用户拒绝授权不显示错误 Toast，只恢复按钮状态。
- 网络、云函数或数据错误显示明确的重试提示。

## 代码边界

- `pages/login/login.*`
  - 登录页视觉、按钮状态、授权、回跳和退出逻辑。
- `pages/index/index.js`
  - 未登录时直接构造登录 URL，不再弹确认框。
- `pages/detail/detail.js`
  - 保留受保护页面的二次登录校验。
- `utils/auth.js`
  - 保留通用登录判断，并提供可直接跳转登录页的统一能力。
- `app.js`
  - 负责全局会话恢复；不承载页面跳转细节。

## 安全与异常处理

- 只接受以 `/pages/` 开头的站内回跳地址。
- 回跳地址必须经过 `encodeURIComponent` 和 `decodeURIComponent`。
- 非法回跳地址一律回到首页。
- 登录按钮在请求期间不可重复点击。
- 页面卸载后不再执行延迟跳转。
- 云函数失败时不写入伪登录状态。

## 验收标准

- 未登录点击首页“穿搭详情”直接进入登录页，没有中间确认弹窗。
- 登录页视觉与编号 3 原型一致，并复用现有开屏背景。
- 点击“暂不登录”能稳定返回首页。
- 取消微信授权后页面仍可再次点击登录。
- 登录成功后进入点击前所选日期的详情页。
- 已登录用户点击详情不经过登录页。
- 直接访问详情页且未登录时会进入登录页，并保留回跳地址。
- 快速重复点击登录按钮只触发一次登录请求。
- 登录失败不会污染本地登录状态。
